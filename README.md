# UrbanForma Minecraft Mod v1.05d

## 项目概述
UrbanForma是一个Minecraft模组，专注于现代城市建设和都市元素，特别是道路系统和城市基础设施。该模组提供大量高精度的道路标线、路缘石以及丰富的彩色建筑方块，帮助玩家创建逼真的现代都市环境。

## 主要特性
- 完整的道路系统：包含各种道路标线、斑马线、转弯标记等
- 丰富的建筑方块：72种精心挑选的颜色系列，每种包含普通方块、发光方块、半砖和楼梯
- 多语言支持：支持中文、英文、日语、韩语和俄语
- 高精度贴图：16x16和32x32贴图，满足不同建筑风格需求
- 专为创造模式设计：为建筑师和城市规划者提供理想的工具集

## 内容总览

### 创造模式标签页
UrbanForma模组提供三个专门的创造模式标签页，便于管理和使用：

1. **都市构方基础 (UrbanForma Base)**
   - 包含所有72种颜色的基础建筑方块
   - 每种颜色包含普通方块、发光方块、半砖和楼梯
   - 覆盖从纯色到传统东方色彩的完整色系

2. **都市构方道路 (UrbanForma Roads)**
   - 多种道路材质（灰色、浅灰色、白色）
   - 完整的道路标线系统
   - 不同高度的路缘石方块

3. **都市构方其他 (UrbanForma Others)**
   - 特殊道具和工具
   - 未来功能预留空间

### 道路系统详解
- **基础道路**：提供不同颜色和材质的道路表面
- **方向性标记**：支持玩家朝向放置的道路标线
- **高度变化**：多种高度的路缘石和台阶
- **标记类型**：中心线、斑马线、转弯线、T型线、十字线等

### 建筑方块色系
- 基础色系：白、黑、灰度系列
- 传统色系：东方传统色彩，如樱花色、利休鼠色等
- 现代色系：现代建筑常用色彩
- 特殊色系：专为特定建筑风格设计的色彩
