# UrbanForma Minecraft Mod v1.08

## 项目概述
UrbanForma是一个Minecraft模组，专注于现代城市建设和都市元素，特别是道路系统和城市基础设施。该模组提供大量高精度的道路标线、路缘石以及丰富的彩色建筑方块，帮助玩家创建逼真的现代都市环境。
后续更新纯随缘，造建筑缺啥就做啥。可能会先搞个摩天大楼那种玻璃缝，还有地下车库的环氧地坪。
